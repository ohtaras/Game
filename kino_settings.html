Πληροφορίες

Το GitHub token χρειάζεται για αποθήκευση κληρώσεων στο repository.


Πώς να δημιουργήσεις token:

  1. GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
  2. Generate new token → σημείωσε repo scope
  3. Αντέγραψε το token και επέστρεψε εδώ

Το token αποθηκεύεται στο localStorage του browser σου. Δεν αποστέλλεται σε κανένα server εκτός GitHub API.
