Λήψη Ιστορικού

Κατεβάζει όλες τις κληρώσεις του Τζόκερ απευθείας από το OPAP μέσα από τη σελίδα (χωρίς να χρειάζεται να πας στο GitHub Actions) και τις αποθηκεύει στο data/raw/joker_raw.json. Χρειάζεται GitHub token (ρύθμισέ το στις ⚙ Ρυθμίσεις).

Σταθερή Πρόβλεψη (backtested)

Παίρνουμε τις πρώτες 1.000 (ή όσες υπάρχουν) κληρώσεις σαν δείγμα και ψάχνουμε τον σταθερό συνδυασμό 5 αριθμών (+ Τζόκερ) που να έχει πετύχει τις περισσότερες φορές πλήρες 5/5 (με ή χωρίς Τζόκερ) μέσα σε αυτό το δείγμα. Ο συνδυασμός είναι σταθερός — δεν αλλάζει ποτέ μετά τον υπολογισμό του. Σημείωση: επειδή υπάρχουν 1.221.759 πιθανοί συνδυασμοί 5 αριθμών, είναι στατιστικά αναμενόμενο το πλήρες 5/5 να συμβαίνει 0 ή 1 φορά ακόμα και για τον καλύτερο σταθερό συνδυασμό — δείχνουμε γι' αυτό και τα μερικά ταιριάσματα (4/5, 3/5 κ.λπ.) για πιο ουσιαστική εικόνα.
